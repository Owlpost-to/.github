# .github

The GitHub organisation profile for Owlpost: `profile/README.md` is what
[github.com/Owlpost-to](https://github.com/Owlpost-to) shows.

`assets/org-banner.png` and `assets/org-avatar.png` are rendered in
[`Owlpost-to/website`](https://github.com/Owlpost-to/website) by
`tools/render-og.sh` (the banner is its `assets/readme-banner.png`). The avatar
is uploaded by hand at `github.com/organizations/Owlpost-to/settings/profile`;
GitHub has no API for it.
